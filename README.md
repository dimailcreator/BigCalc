# BigCalc

BigCalc --- это экспериментальный высокоточный калькулятор,
ориентированный на вычисления с большими числами, расширяемый синтаксис
и развитие собственного математического ядра.

Проект состоит из нескольких уровней:

- математическое ядро;
- слой разбора выражений;
- Web-интерфейс;
- Android-обёртка.

Главная цель проекта --- создать калькулятор, который не ограничивается
обычным JavaScript `Number` и способен работать с вычислениями,
требующими контролируемой точности.

# Математическое ядро

Ядро разрабатывается отдельно от интерфейса.

Оно не зависит от:

- HTML;
- CSS;
- DOM;
- Android API;
- конкретного UI.

Основные идеи:

## Точные значения

Простые выражения должны вычисляться без потери точности.

Пример:

    1/3 + 1/6 = 1/2

---

## Lazy evaluation

Сложные числа вычисляются только тогда, когда нужны цифры результата.

---

## Verified digits

Калькулятор должен показывать только те цифры результата, которые были
подтверждены вычислением.

---

# Принципы проекта

## Корректность важнее скорости

Сначала создаётся корректное решение, затем добавляются оптимизации.

## Ядро отдельно от интерфейса

Математика должна оставаться переносимой.

Исправление математической ошибки должно сопровождаться тестом.

## Расширяемость

Новые возможности должны добавляться без переписывания архитектуры.
